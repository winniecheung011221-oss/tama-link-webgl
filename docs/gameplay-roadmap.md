# TAMA LINK 玩法与体验优化规划

## 产品判断

当前版本已经能展示设备、宠物、房间与基础照顾动作，但互动之间缺少连续因果：玩家完成一次操作后，没有明确的下一目标、策略选择或稀有奖励期待。因此第二阶段应从“功能陈列页”转向“短循环养成游戏”。

核心体验目标：

- 玩家进入后 10 秒内知道宠物现在想要什么。
- 每 30–90 秒完成一次“请求 → 行为组合 → 能量奖励”的微循环。
- 每次 5–10 分钟的游玩至少包含一次阶段性奖励或新发现。
- 所有点击、悬停、成功和解锁都有清晰的视觉、声音与数值反馈。

## P0：本轮已实现

### 请求驱动的照顾循环

- 宠物会提出 Feed / Play / Clean / Sleep 请求。
- 匹配请求会获得额外亲密度和 Signal Energy。
- 完成匹配请求后自动生成下一个请求，形成连续目标。

### Care Combo

- 连续选择不同照顾行为会提升 Combo。
- 重复同一行为会重置组合，鼓励玩家轮换玩法。
- Combo 会提升星尘与能量收益。

### Signal Burst

- 照顾和小游戏为 Signal Energy 充能。
- 达到 100% 后可释放 Signal Burst。
- Burst 奖励星尘、亲密度和一枚 Memory Fragment。

### 小游戏连击

- 接星星加入 1–4 倍连击倍率。
- 需要在短时间内连续命中，失误或间隔过久会重新计算。
- 分数同时服务于奖励、挂件解锁和每日任务。

### Memory Archive

- 新增三段可见的收藏进度与插图占位。
- 分别在 1、3、5 次 Burst 后解锁。
- 后续正式插图可直接替换占位，不改变玩法结构。

## P1：下一轮建议

1. 给 Feed 增加“停在甜蜜区”的力度条，食物品质影响奖励。
2. 给 Clean 增加 5–8 秒擦拭手势小游戏，污渍位置随机。
3. 给 Sleep 增加三拍节奏安抚，准确度影响恢复量。
4. 新增随机事件：礼物、打喷嚏、停电、流星夜、神秘访客。
5. 房间加入可点击热点和少量可摆放收藏物。
6. 宠物状态低于阈值时改变动作、表情、气泡与音乐层。

## P2：内容扩展

- 七日陪伴任务和连续登录故事。
- 性格倾向：活泼、贪吃、爱干净、夜猫子。
- 不同照顾习惯导向不同回忆图鉴与房间装饰。
- 每月主题事件，但保持单机、本地存档即可游玩。

## 验收指标

- 首次互动时间小于 10 秒。
- 普通玩家 2 分钟内可完成第一次 Signal Burst。
- 每种主要行为具备前馈、过程反馈、结果反馈。
- 每次奖励都有数值变化、动效和收藏进度变化。
- 移动端核心按钮无需横向滚动即可操作。

## 需要生成的插图

统一要求：16:10 横向构图，建议 1600×1000 PNG；主体位于画面中央偏下；黑色或透明背景；黑绿荧光像素界面风格；不要文字、边框、UI 或水印。插图会放入 Memory Archive 卡片，并以轻微扫描线和辉光展示。

1. **初次连接 / First Link**
   - Meowchi 隔着绿色发光屏幕第一次伸出爪子。
   - 情绪：好奇、克制、带一点科技感。
   - 色彩：黑、荧光绿、少量银白。

2. **深夜零食 / Midnight Snack**
   - Meowchi 抱着布丁和草莓，周围有少量星尘粒子。
   - 情绪：偷偷开心、温暖、有生活感。
   - 色彩：荧光绿、奶油黄、草莓红点缀。

3. **秘密花园 / Secret Garden**
   - Meowchi 在微型数码花园中追逐像素萤火虫。
   - 情绪：梦幻、安静、稀有奖励感。
   - 色彩：深黑、酸性绿、少量紫色。
